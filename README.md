# Tashkent Housing Price Prediction 🏠📉

This project focuses on predicting apartment prices in Tashkent, Uzbekistan, using various Machine Learning regression models. It includes data preprocessing, feature engineering, and model evaluation based on real estate data.

## 🛠️ Models Trained & Evaluated
In this project, we implemented and compared the following machine learning models:
* **HistGradientBoostingRegressor** (Best Performing)
* **Random Forest Regressor**
* **Ridge Regression**

## 📊 Performance Metrics (Sample Results)
* **HistGradientBoosting**: R² ~ 0.854 | MAPE ~ 14.0%
* **Random Forest**: R² ~ 0.825 | MAPE ~ 14.6%
* **Ridge Regression**: R² ~ 0.760 | MAPE ~ 18.8%

## 💡 Acknowledgments
* Data source: Publicly available Tashkent real estate listings.
* This project was developed as a clone/learning exercise to practice Machine Learning pipeline creation, regression analysis, and hyperparameter tuning.
